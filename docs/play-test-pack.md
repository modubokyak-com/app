### B-3. 앱 액세스 권한 메모 / 검토 메모 (심사자용)

Android에서 1분 점검(입력·결과 확인)은 로그인 없이 되지만, **결과 저장과 복약 알람은 로그인이 필요하다**

심사용 계정은 미리 가입해 두고 동의·이름까지 마쳐 둔다(심사자가 동의 화면을 거치지 않게).

| Username (사용자 이름) | `play-review@modubokyak.com` |
| Password (비밀번호) | `<Play Console에만 입력>` — 이 문서·저장소·채팅에 적지 않는다 |
| Any other information (기타 안내) | 아래 영어 블록 |

```
The 1-minute medication check works without signing in. Saving results and medication alarms require sign-in.
```

## C. 대표가 누르는 순서

### C-1. 콘솔 준비 (30분)

1. Play Console → 앱 만들기(이미 있으면 건너뜀): 이름 "모두의 복약", 기본 언어 한국어, 앱, 무료. 패키지명은 AAB 올릴 때 자동으로 `com.care.bokyak` 고정.
2. 대시보드 "앱 설정" 할 일을 위에서부터: B-2 표대로 답한다. 데이터 보안은 B-4, 전체 화면 인텐트는 B-5(영상 링크 필요 → C-3 먼저).
3. 스토어 설정 → 기본 스토어 등록정보: B-1 글, 아이콘, 그래픽, 스크린샷(C-3).
4. 스토어 설정 → 스토어 설정: 카테고리 의료, 연락처.

### C-2. AAB 업로드 → 내부 테스트 → 비공개 테스트

1. 테스트 → **내부 테스트** → 새 버전 만들기 → D절의 AAB 업로드. 처음이면 "Play 앱 서명" 동의(그대로 계속).
2. 출시 노트 B-6 → 저장 → 버전 검토 → 내부 테스트로 출시. 심사 없이 몇 분 안에 설치 링크가 생긴다.
3. 개발자·대표 기기에 내부 테스트 링크로 설치 → 체크리스트 7절(잠금 화면 알람, 권한, 1분 점검)만 확인.
4. 테스트 → **비공개 테스트** → 트랙 만들기(이름 "14일 테스트") → 테스터 탭: 이메일 목록 만들기(C-4의 주소) 또는 Google 그룹 → 국가 대한민국 → 새 버전: "내부 테스트에서 가져오기"로 같은 AAB → 검토 제출.
5. 심사(보통 하루 안, 길면 며칠). 승인되면 테스터 참여 링크(`https://play.google.com/apps/testing/com.care.bokyak`)가 활성화된다.

### C-3. 스크린샷·영상 (실기기, 20분)

내부 테스트 빌드를 설치한 기기에서, 가짜 이름("홍길동")과 가짜 약("혈압약", "당뇨약")으로:
- 홈(다음 복약 시간이 보이는 상태) · 알람 화면(잠금 해제 상태에서 찍어도 됨) · 1분 점검 결과("확인 필요 1건": 철분 + 갑상선약) · 내 약장. 세로 9:16 그대로 캡처하면 규격을 만족한다(1080×2400 등).
- 영상은 B-5 순서대로 화면 녹화(삼성: 빠른 설정 → 화면 녹화).

### E-2. 5분 시나리오 (첫날)

```
1. 알람 설정에서 시각을 지금보다 2~3분 뒤로 → 홈 → 화면 끄기 → 알람이 뜨면 "지금 약 먹기"
2. 아래 "1분 점검" → 영양제 [철분], 약 [갑상선약], 60대 이상 → 분석 → "확인 필요 1건"이 나오는지
3. 아래 "내 약장" → + 버튼 → 약 하나 더 등록(아무 이름)
4. 알림이 안 울리거나 글자가 잘리거나 멈추면 캡처
```

5. 막히거나 이상했던 화면 (캡처)
